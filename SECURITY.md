# Security policy

This extension runs inside a user's logged-in TikTok tab and can perform account actions. Treat it as sensitive software.

## Do not publish

Never post cookies, authorization headers, tokens, account exports, or unsanitized extension logs. Logs may contain public post IDs and TikTok paths even though the extension does not send them to an external server.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting when available. If it is unavailable, open a minimal issue that contains no exploit details or account data and ask the maintainer for a private channel.

Reports about accidental clicks, incorrect state detection, or browser-specific behavior should include a sanitized log excerpt and the exact extension version.
